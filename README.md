# NewsPulse

NewsPulse is a news analytics dashboard for exploring news articles, analyzing sentiment, and visualizing trends across categories and years.

## Features
- Search and explore news articles
- Analyze sentiment using VADER
- View category-wise and year-wise trends
- Interactive analytics visualizations
- REST APIs for news data and analytics

## Technology Stack
- React, Vite, Axios
- Node.js, Express.js, REST APIs
- Python, VADER
- MongoDB Atlas
- Plotly
